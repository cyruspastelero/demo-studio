## Making a new demo

Start Claude Code in this folder and ask for it with the goal, for example:

> Make a demo of github.com/org/repo: what it does, who it is for, where it runs.

The one thing you do yourself: log in to every site the demo touches in the **Playwright MCP
browser**, with sandbox or test accounts.
