Your real app, filmed and finished

Tell Claude Code, Codex, Cursor, Gemini CLI or Copilot what the demo should show. It writes the plan and, if you like, a storyboard of every scene in your product's font and colours. Then it clicks through your product in Chrome, records each scene with secrets blurred, and cuts the video.

Fix the cut yourself

This is the real editor, opened on the todo sample. Scrub the timeline, retime a shot, drag text on the video or rewrite a voiceover line. On your machine it saves to demo.json and renders. Here, edits stay in this tab.

Pick a look, or copy one

The window, zooms, titles, ending and loudness all come from one template.json. Four looks are built in. Point the agent at a video you like and it measures that look and saves it as a new template.

Voice and music, mixed for you

Each shot carries its own voiceover line. narrate.py checks every line fits its shot, voices it, lays music under it and mixes to -14 LUFS. Use macOS say, your own recordings, or ElevenLabs if you choose.

Sound effects and music are included. The effects are CC0 recordings from Kenney (clicks, scrolls, toggles, toasts and more), each placed on the frame its action happens. The nine music tracks cover launch ads and narration beds, free to use in the videos you make.

It runs on your laptop

No account, no cloud service, no telemetry. Footage, plans and renders stay in a demos/ folder that git ignores.

Test accounts only
Recording uses a sandbox or demo login. Steps that cost money or can't be undone stop and ask.
Secrets blurred before capture
Tokens and sensitive fields are masked in the page itself. Passwords stay in your macOS Keychain.
The editor stays local
The studio listens on 127.0.0.1 only, and treats demo folders from other people as untrusted.
What does leave
Your agent talks to its own AI provider as usual. ElevenLabs gets your voiceover text only if you pick it.

It needs Node.js 20+, Python 3.10+, ffmpeg and Chrome. bash scripts/doctor.sh checks each one. Details: dependencies and security policy.

Start with one prompt

Paste this into your coding agent. It sets everything up and asks before installing anything. Prefer to do it by hand? Read the getting started guide.

Set up demo-studio for me so I can make product demo videos.
1. Clone https://github.com/cyruspastelero/demo-studio.git and work inside that folder.
2. Check for Node.js 20+, Python 3.10+, ffmpeg and Google Chrome.
   Ask me before installing anything that is missing.
3. Run npm install, then bash scripts/doctor.sh, and fix what it reports.
4. Add the Playwright MCP server to your MCP settings.
   Command: npx -y @playwright/mcp@0.0.84 --browser chrome
5. Run bash scripts/new-workspace.sh ./demos
6. Tell me if I need to restart you to load the browser tool,
   then how to start my first demo.
Then say

Make a demo of app.example.com. Goal: a new user creates a project and invites a teammate.

On Claude Code you can also install the plugin: /plugin marketplace add cyruspastelero/demo-studio, then /plugin install demo-studio@demo-studio.
