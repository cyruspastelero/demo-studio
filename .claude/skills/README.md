# Why these are links

Each entry here is a symbolic link to the real skill in [`skills/`](../../skills). It lets Claude Code
load the demo-studio skills on its own when you run it inside a clone of this repo.

GitHub shows a link as a one-line file holding its target (for example `../../skills/demo-edit`). That
is expected, not a broken file. To read or change a skill, open it in [`skills/`](../../skills).
