# Why these are links

Each entry here is a symbolic link to the real skill in [`skills/`](../../skills). Coding agents look
for skills in different folders (`.agents/skills/` for Codex, Cursor, GitHub Copilot and others;
`.claude/skills/`, `.cursor/skills/`, `.gemini/skills/`), so each of these folders links to the same
skills, and the agent you use loads them when you run it inside a clone of this repo.

GitHub shows a link as a one-line file holding its target (for example `../../skills/demo-edit`). That
is expected, not a broken file. To read or change a skill, open it in [`skills/`](../../skills).
