# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep criticism about the work and not the person, and
no harassment of any kind. This applies in issues, pull requests, discussions and anywhere else the
project is represented.

To report a problem, contact the maintainer privately through the email on their
[GitHub profile](https://github.com/Cyvid7-Darus10). Reports are kept confidential.
